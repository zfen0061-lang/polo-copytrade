如何输入密钥？

  1. 双击 open-continuous-monitor.cmd 启动持续监测，或打开已经运行的页面。
  2. 已连接时可点“记住当前连接”；首次接入双击 reconnect-readonly-account.cmd。
  3. 只在本机窗口隐藏输入 API Key 与 Secret；该入口会验证并使用 Windows 当前用户加密保存。
  4. 记住连接后，后台重启或同一 Windows 用户登录后自动重连，不必重新创建 API。

当前持续监测只读取账户，不开启交易。密钥不进入聊天、网页输入框或 GitHub；可点“不再记住连接”删除保存。更换 Windows 用户、撤销 API 或变更可信 IP 后可能需要重新接入。
