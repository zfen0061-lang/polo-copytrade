实盘接入边界

这个 App 的订单都保存在本地模拟账本，不能通过切换开关变成实盘。上线前需要接入经过验证的交易执行器、交易所保护性止损、账户成交推送和恢复机制，并验证数据权限、延迟和交易规则。

GitHub 用于保存代码；GitHub Pages 不会运行这个 Python 后端。请勿上传密钥或将本机服务暴露到公网。
